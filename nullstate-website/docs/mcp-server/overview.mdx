# MCP Server Overview

NullState implements the **Model Context Protocol (MCP)** — a JSON-RPC 2.0 standard for AI agent tool integration.

## Server Endpoint

- **Direct**: `http://localhost:8081` (internal, blocked externally)
- **Proxy**: `POST https://host:8080/mcp` (public, via gateway)

## Compatibility

Compatible with any MCP-enabled client:
- **Claude Desktop** (Anthropic)
- **Cursor** IDE
- **VS Code** (via agent plugins)
- **Custom MCP clients**
