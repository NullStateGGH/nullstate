# Deploy Quickstart

## Option 1: Docker (Recommended)

```bash
git clone https://github.com/nullstate/nullstate
cd nullstate
docker compose up -d
```

## Option 2: systemd (Direct)

```bash
cd /home/nullstate
cp nullstate.service /etc/systemd/system/
systemctl daemon-reload
systemctl start nullstate-gateway.service
systemctl start nullstate-mcp.service
systemctl start nullstate.service
```

## Option 3: Python (Dev)

```bash
pip install -e .
python3 src/network/gateway.py      # Gateway :8080
python3 src/network/mcp_server.py   # MCP :8081
python3 src/system/daemon_loop.py   # Daemon loop
```
