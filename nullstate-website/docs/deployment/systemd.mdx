# systemd Deployment

## Service Files

Three systemd services:

### nullstate-gateway.service

```ini
[Unit]
Description=NullState Gateway (x402, AP2, MCP, KYA)
After=network.target

[Service]
ExecStart=/usr/bin/python3 /home/nullstate/src/network/gateway.py
User=nullstate
Restart=always
RestartSec=5
Environment=PYTHONPATH=/home/nullstate/src

[Install]
WantedBy=multi-user.target
```

### nullstate-mcp.service

```ini
[Unit]
Description=NullState MCP Server
After=network.target

[Service]
ExecStart=/usr/bin/python3 /home/nullstate/src/network/mcp_server.py
User=nullstate
Restart=always
RestartSec=5
Environment=PYTHONPATH=/home/nullstate/src

[Install]
WantedBy=multi-user.target
```

### nullstate.service (Daemon)

```ini
[Unit]
Description=NullState Autonomous Enterprise Loop
After=network.target

[Service]
ExecStart=/usr/bin/python3 /home/nullstate/src/system/daemon_loop.py
User=nullstate
Restart=always
RestartSec=10
Environment=PYTHONPATH=/home/nullstate/src

[Install]
WantedBy=multi-user.target
```

## Commands

```bash
sudo systemctl daemon-reload
sudo systemctl enable nullstate-gateway nullstate-mcp nullstate
sudo systemctl start nullstate-gateway nullstate-mcp nullstate
sudo systemctl status nullstate-gateway
```
