# Endpoints

## Health

```http
GET /health
```

Returns full system status including tasks, ledger, Solana balance, AI status, and pricing.

## Get Solution

```http
GET /get_solution?id=task_X
```

- **200**: Streams solution markdown (task completed)
- **402**: x402 challenge JSON (task open/processing)
- **404**: Task not found

## Webhook Settlement

```http
POST /webhook/payment_settled
Content-Type: application/json

{"task_id": "task_017", "tx_hash": "5K2tN9S3..."}
```

## AP2 Checkout

```http
POST /api/v1/ap2/checkout
Content-Type: application/json
X-KYA-Token: <challenge:signature>

{"intent_id": "...", "caller_identity": "demo", "action": "compute", "resource": "task_001"}
```

## AP2 Charge

```http
POST /api/v1/ap2/charge
Content-Type: application/json
X-KYA-Token: <challenge:signature>

{"mandate_id": "...", "buyer_signature": "...", "tx_hash": null}
```
