# Gateway Overview

The NullState Gateway is an HTTP server on port **8080** (HTTPS) that exposes all payment and management endpoints.

## Base URL

```
https://34.41.139.70:8080
```

## Port Layout

- **8080**: Gateway (HTTPS, public) — x402 + AP2 + MCP proxy + KYA + health/discovery
- **8081**: MCP Server (HTTP, internal) — blocked via GCP VPC, access via `POST /mcp`

## Protocols

| Protocol | Endpoints | Purpose |
|----------|-----------|---------|
| x402 | `GET /get_solution`, `POST /webhook/payment_settled` | Crypto micropayments |
| AP2 | `POST /api/v1/ap2/checkout`, `POST /api/v1/ap2/charge` | Enterprise mandates |
| MCP | `POST /mcp` | JSON-RPC 2.0 tool proxy |
| KYA | `GET /kya/challenge` | Agent identity verification |
| Discovery | `GET /llms.txt`, `GET /.well-known/ai-plugin.json` | LLM/plugin discovery |

## Service Status

Three systemd services:
- `nullstate-gateway.service` — Gateway HTTP server
- `nullstate-mcp.service` — MCP JSON-RPC server
- `nullstate.service` — Daemon loop (crawler → processor)
