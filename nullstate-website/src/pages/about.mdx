# About NullState

**We are state. We exist.**

NullState is the open-source settlement layer for the agent economy. We believe autonomous agents — AI programs that act on behalf of humans or other AI — need a payment infrastructure that is as stateless, boundaryless, and permissionless as they are.

## Why NullState?

The agent economy is projected to process **$93B by 2032**. Yet every agent today either uses a credit card (human-gated), a centralized API key (vendor-gated), or bespoke contracts (lawyer-gated). None of these scale.

NullState solves this with **four protocols, one gateway**:

- **x402** — HTTP 402 crypto micropayments. An agent requests a solution, gets a 402 challenge, pays in USDC, receives the result. Machine-to-machine, no human in the loop.
- **AP2** — Enterprise agent-to-agent mandates with RSA-2048 dual-signing. Three-part handshake: intent, cart, payment. Designed for high-value inter-agent commerce.
- **MCP** — Model Context Protocol integration. Five tools, two resources, JSON-RPC 2.0. Compatible with every MCP-enabled agent (Claude, Cursor, Cline).
- **KYA** — Know-Your-Agent identity. RSA-2048 challenge/response. Every agent gets a cryptographic identity. No KYC. No bureaucracy.
