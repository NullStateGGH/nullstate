# Brand Guidelines

NullState's visual identity reflects our philosophy: **no state, no boundaries, no noise.**

## Logo

The NullState logo mark is a geometric null-set symbol: two concentric circles with a diagonal strike-through. It represents zero state, zero limits, zero permission required.

### Logo Usage

- **Minimum clear space**: 50% of the mark width on all sides
- **Minimum size**: 24px (mark only), 180px (full lockup)
- **Do not**: rotate, skew, recolor, outline, or apply effects

## Colors

| Token | Hex | Usage |
|-------|-----|-------|
| Primary Green | `#00ff9d` | Accents, links, CTAs, active states |
| Near Black | `#030303` | Backgrounds |
| Surface | `#080808` | Cards, sections |
| Border | `#1a1a1a` | Dividers, strokes |
| Body Text | `#e6edf3` | Primary copy |
| Muted Text | `#666666` | Secondary copy |

## Typography

- **Headings**: Inter, SF Pro Display, system sans-serif — 700 weight
- **Body**: Inter, system sans-serif — 400 weight
- **Code**: JetBrains Mono, Fira Code — monospace

## Voice

- **Confident, not arrogant**. We know what we built. We let the code speak.
- **Direct, not verbose**. Every sentence earns its place.
- **Open, not pushy**. We're MIT licensed. Use us or don't. We'll be here either way.
- **No buzzwords**. No "synergistically leverage." No "paradigm shift." Just infrastructure.
